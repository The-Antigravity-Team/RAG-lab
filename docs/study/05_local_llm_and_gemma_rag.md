# 05. 로컬 LLM(Gemma) 연동과 RAG 증강 생성

## 1. 로컬 LLM과 Ollama
로컬 환경에서 LLM을 실행하면 **데이터 유출 걱정 없이(완전 폐쇄망 지원), API 비용 부담 없이** RAG 시스템을 구동할 수 있습니다.

**Ollama**는 로컬 환경에서 오픈소스 모델(Gemma, Llama, Qwen 등)을 최적화된 양자화(GGUF) 형태로 구동하고, 백그라운드에서 표준 REST API(`http://localhost:11434`)를 제공하는 도구입니다.

---

## 2. Google Gemma 모델의 특징

- Google DeepMind에서 개발한 경량 오픈 가중치 언어 모델.
- Gemini 모델과 동일한 연구 기술을 기반으로 훈련되어 작은 매개변수 대비 탁월한 한국어 및 추론 성능을 보입니다.
- **Gemma 2 시리즈**:
  - `gemma2:2b`: 초경량 (20억 파라미터), 일반 CPU나 저사양 노트북에서도 실시간에 가까운 속도로 동작.
  - `gemma2:9b`: 고성능 (90억 파라미터), 상용 모델에 준하는 우수한 문맥 파악 및 복합 질의응답 능력.

---

## 3. 컨텍스트 증강 프롬프트(Augmented Prompt) 설계

RAG의 성공 여부는 LLM에 제공하는 시스템 프롬프트의 지시(Guideline)에 크게 좌우됩니다.

### 모범 프롬프트 예시:
```text
당신은 주어진 참고 문맥만을 바탕으로 사실에 입각해 답변하는 전문 비서입니다.

[규칙]:
1. 제공된 [참고 문맥]에 명시된 내용에만 기반하여 답변하세요.
2. [참고 문맥]에 답변의 근거가 전혀 없다면 절대로 추측하지 말고 "제공된 문서에서 관련 내용을 찾을 수 없습니다."라고 솔직하게 답변하세요.
3. 답변 시 참고한 문서의 출처나 파일명을 함께 명시해 주세요.

[참고 문맥]:
{context}

[질문]:
{question}

[답변]:
```

## 4. 스트리밍(Streaming) 출력의 중요성

로컬 LLM은 클라우드 대형 서버에 비해 1초당 토큰 생성 속도가 제한적일 수 있습니다.
전체 답변 생성이 끝날 때까지 기다리지 않고, 모델이 생성하는 글자를 즉시 한 글자씩 터미널이나 UI에 찍어주는 **스트리밍(Streaming)** 기법을 적용하면 사용자가 느끼는 응답 지연 체감 시간(Time To First Token)을 0.5초 이내로 단축할 수 있습니다.
