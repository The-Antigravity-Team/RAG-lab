[파이썬 비동기 프로그래밍 및 동시성 제어 요약 매뉴얼]

1. 파이썬의 동시성(Concurrency)과 병렬성(Parallelism)의 차이
동시성은 여러 작업을 번갈아 가며 처리하여 마치 동시에 실행되는 것처럼 보이게 하는 논리적 개념이며, 병렬성은 여러 CPU 코어가 물리적으로 동시에 여러 작업을 처리하는 물리적 개념입니다.

2. GIL (Global Interpreter Lock)의 영향
CPython 인터프리터에는 GIL이 존재하여, 멀티스레드를 사용하더라도 순수 CPU 연산 작업은 한 시점에 하나의 스레드만 바이트코드를 실행할 수 있습니다. 따라서 CPU 집약적 연산(이미지 처리, 대규모 수치 계산)에는 multiprocessing 모듈을 사용해야 진정한 병렬 처리 이득을 얻을 수 있습니다.

3. I/O 바운드 작업과 asyncio
네트워크 요청(HTTP API 호출), 파일 입출력, 데이터베이스 쿼리와 같은 I/O 바운드 작업에서는 대기 시간(Waiting Time)이 대부분을 차지합니다. asyncio는 단일 스레드 기반의 이벤트 루프(Event Loop)를 활용하여, I/O 대기 시간에 다른 코루틴(coroutine)으로 제어권을 넘겨 시스템 처리량을 극대화합니다.
async def로 코루틴 함수를 정의하고, await 키워드를 통해 논블로킹 대기를 수행합니다.
